## About

Blood Money is a transparency tool. It lets anyone browse documented cases of Saudi Arabian money behind films and television -- through the Public Investment Fund (PIF), state media companies like MBC, the General Entertainment Authority, or direct production deals.

Every title on this list has a documented source. This is not speculation.

## Contributing

If you know of a title that should be on this list, open an issue or submit a pull request with:

- The title name
- Its TMDB ID (find it at themoviedb.org)
- A one or two sentence description of the Saudi connection
- A link to a credible source (news article, SEC filing, trade publication, etc.)

## Data

All flagged titles live in `data/titles.json`. Poster images and metadata are fetched live from the TMDB API.

## Running Locally

No build step needed. Just open `index.html` in a browser.
